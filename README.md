# analise-feminicidios-brasil
Análise de dados públicos sobre feminicídios no Brasil utilizando Python, Pandas e Tableau
Este projeto tem como objetivo explorar dados públicos sobre feminicídios no Brasil, utilizando técnicas de análise e visualização de dados para facilitar a compreensão das informações.

Ferramentas utilizadas

Python: tratamento e análise dos dados.

Pandas: limpeza, organização e transformação da base.

Jupyter Notebook: desenvolvimento e documentação do código.

Tableau: criação de dashboard interativo.

Etapas do projeto

Importação e exploração da base de dados.

Identificação e tratamento de valores ausentes e inconsistências.

Organização dos dados para análise.

Análise dos registros por período e localização.

Desenvolvimento de visualizações e indicadores.

Criação de dashboard interativo no Tableau.

Fonte dos dados

SINESP - Ministério da Justiça e Segurança Pública
LESFEM - Laboratório de Estudos de Femincídio

Observações

Os resultados devem ser interpretados considerando o período, a cobertura e as definições utilizadas na base de dados. Os registros analisados não necessariamente representam todos os casos ocorridos. Vale ressaltar também que as médias das idades foram calculadas considerando apenas os registros com idades informadas, os valores ausentes não foram interferidos no cálculo da média.
